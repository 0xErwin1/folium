## Metric collection definition

Each run records an initial sample, one RSS/native-heap sample after every iteration, and a final end sample. Peak is `max(all samples)`, including the final end sample; therefore `peak >= baseline` and `peak >= end` by definition. The sample sequences below contain initial, 24 iteration, and final samples. They are observed bounded-iteration evidence, not a numerical production memory budget and not proof that memory cannot grow unbounded over a longer workload.
