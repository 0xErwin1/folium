# RCO-005 OCR quality evidence

## Decision: BLOCKED — measured quality is below the approved threshold

The connected composition test in `:app` renders committed scanned PDFs through the neutral `PdfEngine`/`Raster`/`PageImage` boundary and invokes `TesseractOcrEngine`; no production cross-adapter dependency was added. It exercises Spanish+English data together, Unicode NFC normalization, normalized PageSpace boxes, cancellation, closed, and language-data failure behavior. The test performed five OCR iterations per fixture and included final RSS/native-heap samples in reported peaks.

On both API 37 x86_64 16 KiB emulators, Tesseract returned no expected tokens from the source-authored 5x7 raster scan corpus. This is an honest acceptance failure: recall is 0.0 rather than the required >= 0.90, and output geometry is invalid because no words were produced. No expected output was changed and no quality result was inferred.
