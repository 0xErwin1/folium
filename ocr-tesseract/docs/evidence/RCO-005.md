# RCO-005 OCR quality evidence

## Decision: conditional acceptance

The required token-and-region acceptance passed on both API 37/x86_64/16 KiB targets. This is not a full-transcription quality pass. The prior diagnostic normalized-stream measurements were high: CER was 1.0556/1.0714 and WER was 1.5/1.0 for OCR-SPA-01/OCR-ENG-01. Token recall therefore does not establish good full-text transcription quality. No CER/WER budget was supplied, so those diagnostics are recorded as residual risk rather than converted into an invented threshold.

## Verification

- `:ocr-tesseract:testDebugUnitTest :reader-core:testDebugUnitTest`: passed.
- `TesseractRuntimeFailureTest`: seven connected lifecycle/error tests passed with zero skips on each target. They prove typed wrong-thread/cancelled/closed, bitmap and input/OOM mapping, recognition-trigger and iterator-acquisition/iteration mapping with retained causes, fatal `Error` rethrow, exact-once bitmap/iterator/native cleanup, and `getUTF8Text()` before iterator acquisition.
- `:app:connectedDebugAndroidTest` filtered to `TesseractFixtureTest`: two tests passed, zero skips on each target.
- Cleared-device logcat and current UTP output were searched for fixture filenames and recognized fixture text; neither contained a match.
- `bash scripts/verify-fixtures.sh`: passed; canonical current equals generation 1 equals generation 2, the copied manifest and every app/engine test asset match their canonical source.

## Corrective design

After `setImage(bitmap)`, the adapter checkpoints cancellation, invokes `getUTF8Text()` to trigger recognition, checkpoints again, obtains and begins the iterator, extracts `RIL_WORD` entries, and deletes the iterator in `finally`. Bitmap recycling is also `finally`-safe. Initialization ownership is isolated in `NativeApiOwner`: failed initialization releases the partial API exactly once; cleanup failures are suppressed; fatal `Error` is rethrown rather than mapped. Language-set changes release and reinitialize the native API. The staged traineddata copy uses a temporary file and `finally` deletion.

Residual risk: the acceptance criterion is token recall plus source-region overlap. High CER/WER means downstream consumers must not interpret this evidence as full-text transcription quality.
