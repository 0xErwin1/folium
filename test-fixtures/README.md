## Regenerate

Run `PYTHONPATH=/path/to/pypdf-5.1.0 python3 scripts/generate-fixtures.py`, then run `bash scripts/verify-fixtures.sh`. The generator uses only fixed source bytes and pypdf 5.1.0; the manifest records each generated SHA-256 value.
